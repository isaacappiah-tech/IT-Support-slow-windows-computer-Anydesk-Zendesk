# IT Support Lab — Slow Windows Computer Troubleshooting

## Overview

This project simulates a Level 1 IT Help Desk incident involving a Windows 10 workstation experiencing slow performance and intermittent freezing.

The incident was documented and investigated using Zendesk, AnyDesk, and Windows troubleshooting tools.

## Scenario

**Company:** GlobalTech Solutions  
**Department:** Sales  
**User:** James Anderson  
**Workstation:** Windows 10 Client 10

### User Report

> "Hi IT Support, my computer has become really slow today. Programs are taking a long time to open and sometimes the computer freezes for a few seconds. It was working normally yesterday. Can someone please help me?"

## Tools Used

- Zendesk — incident/ticket management
- AnyDesk — remote support
- Windows 10 — endpoint troubleshooting
- Task Manager — resource monitoring
- Windows Settings — system and storage investigation

## Help Desk Workflow

1. Received the user's support request.
2. Created a Zendesk incident.
3. Recorded the user's reported symptoms.
4. Sent an initial response to the user.
5. Added internal troubleshooting notes.
6. Obtained user permission for remote support.
7. Connected to the workstation using AnyDesk.
8. Investigated Windows performance.
9. Checked CPU, memory, disk, running processes, startup applications, and available storage.
10. Identified the source of the performance issue.
11. Applied the appropriate corrective action.
12. Tested the workstation after the fix.
13. Asked the user to verify normal performance.
14. Documented the investigation and resolution in Zendesk.
15. Resolved the ticket.

## Investigation Findings

**Observed symptoms:**
- Slow application launches
- Intermittent Windows freezing
- Performance was previously normal


## Verification

After troubleshooting:

- Windows responsiveness was tested.
- Applications were tested.
- The user confirmed that the workstation was functioning normally.

## Key Lesson

A slow computer should not be diagnosed simply by assuming that the computer needs more RAM or that a particular application is responsible.

A Help Desk technician should first gather evidence, identify the resource or process contributing to the problem, make an appropriate change, and verify the result with the user.
